Hearth Ledger is a static, phone-friendly household budget for the Morrow home. It includes **6 pages**, **41 seeded transactions** (27 in November plus 14 in October), **9 spending categories**, and **3 savings goals**, with six bills, editable category limits, local persistence, inline SVG charts, and a one-click demo reset. Open `app/index.html` directly or use `node serve.ts`.
